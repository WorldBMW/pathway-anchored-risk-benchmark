## 摘要

空间转录组模型的训练队列往往只有几十名供者，模型因而可能靠记忆供者身份、而非疾病状态来拟合标签。这类泄漏如今已可被检测，但检测本身并不提供补救手段；而最直接的事后做法——在训练结束后投影掉供者均值方向——会把可迁移的疾病信号连同泄漏一并摧毁。为此我们提出 MRP-ST-Repair：一种训练期患者对抗修复方法，并给出"修复何时能保住信号"的统计理论。修复在振幅、剂量、种子与图骨架各不相同的 75/75 次阳性对照运行中都保住了共享疾病程序，同时检测器在 45/45 次混杂对照运行中保持非盲。一个命题表明，朴素的"先检测、后接受"双门仅在修复前关联—零尺度比 τ_base/σ̂ < 2.35 时可行，我们据此以三轴接受协议取代之。可修复性取决于标签—身份耦合：因果型（病因型）标签——如 HPV 状态——在接受工作点保住 0.38–0.59 的可迁移比例，序数型严重度则完全无法保留。供者数量可行性边界、同源切片膨胀效应，以及角化程序的存活，共同构成这一方法。

**关键词：** 空间转录组；信息泄漏；对抗训练；模型审计；可迁移性；头颈癌；HPV

## 引言

面向空间转录组（ST）的深度模型会学习 spot 级与切片级的表示，以支撑聚类、解卷积、空间域识别与结局预测。但可用的队列在结构上极其单薄：Visium 切片成本高昂，一项典型研究通常只包含几个到几十个患者。当同一患者贡献多个 spot 或几张切片时，任何在 spot 级划分上训练的模型，都可以靠判断某个 spot"来自哪位患者"、而非"代表何种疾病状态"来取得好成绩。这种失效模式如今已可被度量：在姊妹研究[1]中，我们提出了校准的标签依赖指数（LDI），可在置换推断下检测此类患者分块泄漏，并显示在宫颈肿瘤队列内几乎完美拟合严重度标签的模型（样本内 AUROC 1.00），在留一供者（LODO）评估下会跌至随机水平（AUROC 0.497）。

不过，检测只是问题的一半。本文要回答的是一个建设性问题：已知某个已训练的 ST 模型正在泄漏，我们该如何移除泄漏，同时又如何保住模型真正学到的疾病信号？最直观的答案——在训练之后对嵌入做清理——并不奏效，下文将说明原因：训练完成后，供者身份与疾病信号已经折叠进同一批方向，任何事后滤波器去掉其中一个，都必然连带去掉另一个。因此，修复必须内建于训练过程，并且必须配上一套判据，既证明泄漏已被消除，又证明信号得以保留。

最接近的既有工作各自解决的是不同问题。批效应与患者稳健的对比编码器（如 arXiv:2503.07173）[2] 能生成跨供者一致的表示，却不提供泄漏度量、校准的接受判据或工作特性；群体稳健性目标（Group-DRO,[3] 不变风险最小化[4]）能抑制虚假相关，却没有任何仪器去验证标签依赖是否真的被移除；批校正方法（Harmony,[5] 类 scVI 的条件模型,[6] 空间对齐工具）只对齐切片之间的分布，与移除嵌套在患者内部的标签依赖是两回事；供者不相交划分则是一种预防手段，而非对已训练模型的补救。在基因组学之外的机器学习领域，通过时间维度的训练—测试划分来追踪测试集泄漏的污染溯源流程（语言模型评测）[7] 与我们精神相通，但既不涉及空间结构，也不涉及我们的生物学终点。

本文提出 MRP-ST-Repair——一种在保住信号的前提下对 ST 模型去身份化的训练期方法，并贡献三项我们认为可超越 ST 的发现：

1. **一个可证明不破坏共享信号的训练期修复算子（C1）。** 患者对抗算子族与编码器一同训练；用于检测的同一校准仪器被复用为接受裁判，从而同时给出检测与修复的实测工作特性。在 75 次阳性对照运行中，共享疾病程序在每个剂量下都存活；检测器在 45 次身份混杂运行中保持非盲。
2. **一套将检测与接受相分离的统计理论（命题 1）。** 我们证明"先检测后接受"双门仅在修复前标签关联相对于零假设尺度足够小时才可行——也就是说，恰恰是让检测成立的统计量（较大的 LDI）会使朴素接受门在结构上不可行——并引入三轴接受协议来化解这一混同。
3. **对修复何时能保住信号的定量刻画。** 在仿真真值队列与两个真实肿瘤队列上，可修复性由队列结构决定：标签—身份耦合类型（病因型还是序数型）决定保留预算，供者数量可行性边界（在参考信号下 n* ≈ 16–32 名供者，随信号减弱右移）决定结构前提。此外，一个"同源切片膨胀"效应表明，切片级交叉验证会在多切片队列中系统性高估泛化，必须以供者级留出替代。

令人欣慰的是，修复后存活下来的确实是真实生物学：在一个外部头颈鳞癌（HNSCC）队列中，经受接受性修复而存活的 HPV 状态信号，正好对应经典的鳞状分化／角化程序。

## 结果

### 一个保住共享信号的训练期患者对抗修复算子

**为何修复必须在训练期施加。** 对已训练模型而言，最省事的修复是用事后投影移除嵌入中的患者均值子空间（身份残差化）。因为它无需重训，我们最先测试了它——在宫颈队列与各仿真臂上都做了尝试——结果它在机制上失败。在宫颈队列上，投影掉单个患者均值方向（k = 1）时，样本内标签关联原封不动（τ_in 保持 0.46），而跨患者迁移的那一部分——留一法（LOO）关联——被摧毁（τ_LOO 均值由 0.46 降到 −0.08；逐种子 −0.38 至 +0.19）；把投影加到 k = 2，两者一起崩塌（τ_LOO −0.44，τ_in 0.05）。在共享程序仿真上（其疾病程序是振幅已知、供者可迁移的共享信号，见实验方法），崩塌立即而彻底（k = 1 时 τ_LOO 由 0.71 掉到 −0.71，τ_in → 0.02）。换言之，该投影既删掉了患者特异的干扰指纹，也删掉了可泛化的疾病信息，因为训练之后二者占据了同一子空间（图 1B）：模型早已把患者身份与疾病信号折叠进联合方向，事后线性滤波器无法把它们拆开。只看记忆容量的样本内指标仍居高不下，而可迁移信号早已消失，且毫无预警。这一阴性结果界定了后续全部工作的设计空间：必须在训练过程中就把患者身份方向挡在表示之外。这正是 MRP-ST-Repair 采用训练期方法的原因。

**修复算子（方法 B）。** 我们在 spot 级空间图上训练一个图注意力编码器[8]（k 近邻，k = 6，并施加较大的坐标偏移以阻断跨切片连边），配一个重建表达量的线性解码器；再通过梯度反转层（GRL）[9,10] 接上一个患者分类对抗器，其反转强度按 α = min(1, 2·epoch/T) 逐步上升（稳定性加固变体只在对抗器预热 50 个 epoch 之后才开始上升，此前 α = 0）。对抗器努力最大化患者身份准确率，编码器则借反转尽量压低它。单一超参数 λ 控制对抗项的权重：λ = 0 即未修复基线，λ 越大修复越强。

**安全性：强共享程序在每个剂量下都存活。** 一篇声称能"移除泄漏"的方法论文，首先得证明它没有把"一切"都移除掉。我们在共享程序阳性对照队列上做了安全性面板，覆盖程序振幅 {0.5, 1.0, 1.5, 2.5}、对抗剂量 λ ∈ {0, 0.5, 1, 2, 5}，GAT 编码器三个种子（60 次运行），外加 GCN 编码器在参考振幅下（15 次运行）。在全部 **75/75 次运行**中，修复后的 LOO 关联都停在队列类规模对应的解析天花板（50-vs-40 供者时为 τ = 0.707，即该二元标签多重度下可达到的最大 Kendall τ，推导见实验方法；每次运行的可迁移比例 R ≥ 0.989），并且在每个剂量下 LDI 都维持在高基线（参考振幅约 5.8，全振幅范围 5.6–6.1）（图 2A）。这是正确的结果而非失败：共享的、供者可迁移的程序本就应当在去身份化后存活，检测器也本就应当继续把它判为真实的标签依赖。修复熄灭的不是真信号，而是患者身份。

**非盲性：修复后检测器仍能区分真信号与虚假信号。** 在身份混杂对照队列上——每位供者无论属于哪一类都携带振幅相同的供者特异通路指纹，因此标签只能靠记忆身份来拟合——修复后的模型在 45/45 次运行中（覆盖 GAT、GCN 与一个稳定性加固变体；图 2B）都被正确判为无依据：LDI 从未越过 1.645 门。可见检测器的误报行为在修复后依然保持。在弱信号加异质性队列上，基线时三个种子只有一个可检出；中等强度修复（λ = 0.5）使三个种子的关联全部上升（平均 τ 由 0.05 升至 0.145，两个原本不可检出的种子由 −0.03 升至 +0.13），但都没有越过校准门（逐种子 LDI 1.08–1.39；表 S1）。这是一个虽小但一致的"去身份化作为预处理"效应；我们如实报告其幅度，不据此下任何结论。

**骨架通用性。** 把 GAT 编码器换成图卷积编码器[11]后，安全性面板（15/15 运行在天花板）与非盲性结果（15/15 无误报）被精确复现，外部队列的剂量—响应形状也得到复现（表 S5）。可见该修复机制并非注意力机制带来的假象。

### 将检测与接受相分离的统计条件（命题 1）

修复算子只有配上合适的判据才有用，该判据需同时确认泄漏被移除、信号被保留。朴素的接受看似需要两个条件：标签依赖消失（LDI < 1.645，即校准的检测门），并且可迁移信号被保留（τ ≥ c·τ_base，协议取 c = 0.7）。命题 1 表明，这两个条件会以"可由修复前量预测"的方式相互冲突。

> **命题 1（双接受门的可行性）。** 设 LDI(τ) = (τ − τ⊥)/σ̂ 为校准指数，关于 τ 严格递增，门值 1.645，零假设下界 τ⊥ ≈ 0。双门 {LDI < 1.645 ∧ τ ≥ c·τ_base} 在修复后的 τ 可行集非空，当且仅当 c·τ_base < τ⊥ + 1.645·σ̂，即当 c = 0.7 时 **τ_base/σ̂ < 1.645/c + τ⊥/(c·σ̂) ≈ 2.35**。
>
> **推论 1。** 对任何真实基线关联 τ_base > 0 固定的队列，只要队列足够大（随供者数增加，σ̂ → 0），双门在结构上就是空集——因为此时门要求 τ 近零，而保信号又要求 τ 达到 τ_base 的较大比例。于是，恰恰在信号最强时，双门把"泄漏被移除"与"信号被移除"混为一谈。

*证明.* 由单调性即得：LDI < 1.645 ⟺ τ < τ⊥ + 1.645σ̂；它与区间 [c·τ_base, τ_base] 相交非空，当且仅当 c·τ_base < τ⊥ + 1.645σ̂。∎

该命题并非纸上谈兵，它精确预测了我们的实验结果（表 1）。共享程序仿真的 τ_base/σ̂ = 5.8，宫颈队列约 2.4，都高于约 2.35 的阈值——因此在这两处，**没有任何**修复剂量能通过双门，这是由构造决定的，并非失败。外部 HNSCC 队列的 τ_base/σ̂ 约为 2.2，刚好落在阈值之下，是三者中唯一存在接受窗口的队列，也是实际观察到接受工作点的队列。一位不了解这套代数的设计者，会错误地认定修复在每一个强信号队列上都"失败"了。

因此我们用**三轴接受协议**取代双门：（i）**安全性**——阳性对照上可迁移关联 τ_LOO 相对基线得以保留；（ii）**泄漏削减**——样本内记忆差（τ_in − τ_LOO）收窄，身份混杂对照上的指纹贡献下降；（iii）**非盲性**——修复后仪器仍能正确分级已知对照（真实程序判为有依据，身份混杂判为无依据）。这样一来，接受所表述的是"剩下的是哪一种标签依赖"，而不再要求所有标签依赖一概消失。

这里还需一句量化的诚实交代。在身份混杂对照上，修复对样本内指纹的清除只做到部分完成（最强剂量下约削减 12%，跨种子与跨稳定性加固变体都稳定；表 S2）：被记忆的身份不仅搭乘我们植入的通路指纹，还搭乘计划之外的供者特异成分（批偏移、空间场相位）。这恰好为轴（ii）提供了校准——样本内 τ 是记忆容量的上界，而非校准的泄漏度量，这也正是该仪器采用 LOO 基的 LDI、而非 τ_in 的原因。

### 可修复性源于标签—身份耦合，而非方法本身

两个真实队列，两种标签类型，同一方法，结果截然相反。

**宫颈肿瘤（序数型严重度；35 张 Visium 切片）。** 在身份信息不受限的情况下，基线模型的 LOO 关联相对于零假设尺度较大（τ_LOO ≈ 0.42；λ = 0 时 LDI ≈ 2.4–2.5；表 S3）。施加修复剂量后出现双稳态，且在稳定性加固（对抗预热、梯度裁剪、对抗头谱归一化）之后依然如此：低剂量（λ ≤ 1）下 LDI 保持在门之上（2.00–2.52）；高剂量（λ ∈ {2, 5}）下每个种子都出现了门下运行（LDI 0.62–1.15），只保住 27–50% 的可迁移关联；而且响应忽高忽低、并不单调——同一种子可能在一个高剂量下高于门、在另一个高剂量下低于门（例如某种子 λ = 2 时 LDI 2.41、λ = 5 时 0.80，另一种子 λ = 2 时 1.15、λ = 5 时 2.42）。可见不存在稳定的中间工作点。机制解释很直接：序数型严重度标签——正常、高级别上皮内病变、癌——编码了每名患者各自的病理史；在小队列里，严重度与身份几乎是同一个变量，因此任何强到足以剥离身份的剂量，也会连带剥离标签。与此一致，姊妹研究在同一结构上观察到 LODO AUROC 由 1.00 崩塌至 0.497。

**HNSCC，外部验证（病因型二元标签；16 名患者，GSE268014）。** 我们下载了一个公开的 HPV 阳性与阴性头颈肿瘤 Visium 队列，训练同一套修复栈。全文用可迁移比例 R = τ_LOO/τ_in 来刻画修复结果——即一次运行在样本内拟合的内容中，真正跨供者迁移的份额（在解析天花板上 R = 1）。其剂量—响应在定性上不同，并且首次在真实队列中于两个统计量上都完整且非单调（表 2；图 2C）：LDI 随剂量降到 λ = 0.5 附近的最小值（1.13–1.37，三个种子全部过门），随后部分回弹；R 先降后升，其中一个种子在最大剂量下恢复到 R = 0.90 的可迁移比例（τ_LOO = 0.64）；在独立的非加固复跑中，同一种子与剂量达到 8-vs-8 患者对应的解析天花板（τ_LOO = τ_in = 0.7303，即理论最大值），也就是一个**完全供者可迁移泛化**的工作点（表 S4）。接受工作点（LDI < 1.645）出现在 λ ∈ {0.5, 1, 2} 上——九个种子×剂量单元中有七个，且 λ = 0.5 时三个种子全部通过——这些单元的可迁移比例落在 R = 0.38–0.59（非加固复跑重现了相同形状，λ = 2 时逐种子 R 0.34–0.75；表 S4）。置换深度几乎不影响结论：以 B = 10,000 替代 2,000 次置换重算零假设，15 次外部队列运行中没有一次门判决被翻转，σ̂ 变动不超过 4.4%，LOO 统计量则逐位一致。

**这一对比本身就是发现。** 病因型标签——究竟是哪一种病毒导致了肿瘤——外在于患者身份：许多患者共享同一病因，它诱导的分子程序（细胞周期进入、鳞状分化）是真正共享的。序数型严重度标签则内在于患者病史。在方法与剂量安排完全相同的前提下，病因型标签在接受工作点保住了 0.38–0.59 的可迁移比例（未修复时为 0.69–0.94；某个最大剂量种子达到 0.90，三轴协议将其判为共享信号存活，而非接受失败），序数型标签则一点也保不住。**因此，可修复性是队列标签—身份耦合结构的一项可测属性**——这是任何计划开展小队列 ST 研究的人都应纳入考虑的设计要素，也是把"外部效度"拆解为一个可在训练前估计的量。

### 供者数量可行性边界——以及检测器本身为何对供者稳健

如果可修复性取决于队列结构，那它如何随患者数量变化？我们生成了一个二维相图：供者 n ∈ {4, 8, 16, 32, 64}（固定 5:4 类比例）、每供者一张切片，以共享供者指纹作为唯一泄漏通道（振幅与阳性对照匹配），第三轴为修复剂量 λ，覆盖两种信号强度（1.0 与 0.3），每单元三个种子。

得到两个结果，一阴一阳，都很有信息量。**阴性结果：** λ = 0（不修复）时，信号 1.0 下 LOO 关联在 n ≥ 8 时保持在天花板——在每供者一张切片时，检测本身对供者稳健，因为 LOO 探针已经堵住了唯一的泄漏通道；在 k = 1 时并不存在检测意义上的"泄漏相边界"。（检测仪器自身的稳健性也是这张相图的一项产出。）**阳性结果：** 修复列呈现出一条清晰的边界（图 3A）。信号 1.0 下，n ≤ 16 时单元均值可迁移比例在多数剂量下崩塌（各供者数的最小值：n = 4 为 −0.67，n = 8 为 0.08，n = 16 为 0.58；逐种子值见表 S8）；而 n ≥ 32 时任何单元的任何剂量都未使单元均值低于 0.86（n = 64 时所有单元均值 ≥ 0.98）：**可行性边界落在 16 与 32 名供者之间**（边界单元的五种子验证见表 S6）。信号 0.3 时边界右移，落在 32 与 64 名供者之间（n = 32 时最差单元均值 0.80）。机制正是前述事后失败的子空间论证，只是上升到了群体层面：供者少时，身份子空间张成（或包含）了程序方向，因此任何压制身份的剂量都会连带压制程序；供者多时，身份方向相互抵消，程序得以存活。信号越弱，在几何上越靠近身份子空间，也就需要更多供者才能恢复。损伤区内的剂量—响应同样非单调（中等剂量最差），与上一节真实队列的表现一致。

这条边界是论断 C2 的定量形式：它给出的是修复的**前提条件**（在给定信号强度下所需的供者预算），而非保证；它也解释了为什么宫颈队列（35 张切片，但每个严重度层内有效信息供者很少，且标签与身份严重耦合）与 16 例 HNSCC 队列（病因型标签，n 略低于信号-1.0 边界但耦合较弱）会各自落在可修复性图谱上的相应位置。

### 同源切片膨胀：切片级交叉验证在多切片队列中高估泛化

相图还揭示了一个影响所有多切片 ST 研究的陷阱。我们以每供者 k ∈ {2, 4, 8} 张切片（16 名供者）重跑切片轴，并比较两个统计量：前面一直使用的切片级 LOO τ，以及**供者级留一供者法** τ（τ_LDO，即把留出供者的所有切片一并移除）。λ = 0 时二者在天花板处重合（18-vs-14 切片类别为 0.713）——共享程序如其所应地跨供者迁移。修复后二者急剧分离（图 3C）：切片级 LOO 在 k ∈ {2, 4, 8} 的全部 45 次运行中都钉在天花板（每个 k 各自处于其类规模天花板），而 τ_LDO 崩塌（k = 2 时：λ = 2 下由 0.713 降到 0.585，λ = 5 下降到 0.230）。切片级划分被**同源切片**悄悄救了回来：留出切片的供者仍通过其兄弟切片留在训练集中，于是所谓"泛化"有一部分其实是身份再识别。姊妹研究所见的 LODO AUROC 崩塌，正是这一效应在真实场景中的表现；在这里，我们用一个旋钮就把它复现并控制住了。因此，我们上文的全部可修复性结论都在 k = 1 下计算，此时两个统计量按构造重合；并把由此得到的建议定为一条协议规则：**在多切片队列中，模型接受必须在供者级度量，绝不能在切片级度量。**

### 修复后存活的是已知生物学

如果修复保住了真正共享的程序，那么存活的表示应当能解码出可辨认的生物学。我们取外部队列中 λ = 2 的 seed-0 运行，在切片均值表示上用岭回归拟合 HPV 状态判别方向（修复后的嵌入空间），再通过该运行自己的线性解码器把该方向映射回基因空间（严格配对：解码器与嵌入属于同一次运行；图 4）。在唯一符号空间（6,586 条目的并集面板含 4,647 个唯一符号）中按 |载荷| 排序，前 100 个基因在鳞状分化／角化程序上显著富集——KRT14、KRT16 与 ID1 位列面板内 11 个 HPV 阳性参考标志物之中，角化家族基因 SPRR1B 与 SPRR3 也在其列（超几何 p = 0.0014，15 个参考标志物中有 11 个存在于面板；经验置换 p = 0.0015，对照零假设期望为每 100 个基因命中 0.23 个标志物）——浆细胞成分（IGKC，排名 2）与基质成分（COL1A2，排名 17）补全了列表前列。这种富集并非某一次运行的偶发：在可得的全部四个严格配对（同运行解码器、同运行嵌入）中，它在 λ = 2 的每个种子上都成立（各处命中两到三个标志物，包括两个过门种子；p = 0.0014–0.022，存活角化基因含 KRT5、KRT6A、SPRR2B、SPRR3），并且在最大剂量恢复点（λ = 5）**最强**，命中六个标志物——其中就有 CDKN2A 本身，即经典的 HPV+ 驱动读数（p < 0.001；表 S7）。存活下来的程序与已报道的 HNSCC 经典 HPV 状态对比一致[12]（CDKN2A/p16 轴的细胞周期进入与角化分化），而且仅凭修复后的表示即可恢复。存活下来的并非"模型还能拟合的随便什么东西"，而是学界早已认可的疾病程序，并且在修复做得最好的地方恰恰最为清晰。我们把它定位为一次演示（C3），而非发现：它通过展示经审计的修复在生物学层面保住了什么，为这一方法画上闭环。

### 修复保住了信号份额，却没有改善下游临床终点

可迁移比例统计量 R 报告一次运行的样本内拟合中有多大份额跨越了供者，但它本身并不说明下游临床任务是否变好。因此我们直接评估外部队列自身的病因学终点——用闭式岭探针在切片均值嵌入上做留一供者（LODO）的 HPV 状态分类（表 S9）。λ = 0 时该终点已显著高于随机（三种子的 LODO AUROC 为 0.906 ± 0.063；三个种子的 LDI 为 1.88–2.49，都在门之上），可见修复前的模型并非仅在记忆身份——它所拟合的关联大部分是供者可迁移的，这与该队列恰好落在命题 1 阈值之下相符。修复并未改善该终点：每个 λ > 0 的均值 LODO AUROC 都低于基线（λ = 0.5 为 0.781 ± 0.072；λ = 1 为 0.766 ± 0.098；λ = 2 为 0.813 ± 0.041；λ = 5 为 0.766 ± 0.189），相对基线下降约 0.09–0.14，其中 λ = 0.5 在三个种子上全部下降，且各剂量的方向一致。这就是修复的**保真代价**，也是该队列上的预期结果而非算子缺陷：该队列为 16 名患者、每患者一张切片，切片级 LOO 与供者级 LDO 统计量按构造重合，因此不存在可供修复移除的同源切片泄漏通道（上一节的同源切片膨胀效应在此不存在）。修复的收益以存在泄漏通道为条件；其代价——对可迁移信号的部分擦除，正是把接受单元的可迁移比例定在 R = 0.38–0.59 的同一效应——无论是否存在泄漏通道都要付出。λ = 5 的种子间跨度（0.563–0.938，SD 0.189，而 λ = 2 为 SD 0.041）进一步说明在该供者数量下强修复的种子不稳定，与 n* ≈ 16–32 边界一致。我们把它作为阴性结果如实报告，并将其读作一条适用范围条件：在每供者单切片的队列上，审计本已认定信号供者可迁移，修复应保留给确实存在泄漏通道——每供者多张切片、或批次—标签耦合——的队列。

## 讨论

MRP-ST-Repair 是一种训练期方法：它移除 ST 模型中的患者身份泄漏，同时保住可迁移的疾病信号。围绕它，我们得到四项我们认为具有普遍意义的发现。

第一，**该方法在"移除"与"保留"两方面都受到度量。** 对强信号体系而言，事后清理可证明是自我挫败的（图 1B 的子空间论证），因此修复被内建到训练中；用于检测的同一校准仪器随后被复用为接受裁判，并且在整条修复族上保持非盲（75/75 阳性对照与 45/45 混杂对照判定；表 1）。

第二，**存在一套关于"接受何时才可能"的理论。** 命题 1 表明，只要修复前关联相对于零假设尺度较大（τ_base/σ̂ ≳ 2.35），朴素的"移除并保留"双门在结构上就是空集——这一条件对多数强信号队列成立，却恰好不适用于唯一观察到接受工作点的那一个队列。这把接受从一个手工设定的阈值，变成一个可以在训练前先行核对的量，也促成了取代双门的三轴协议。

第三，**可修复性与评估卫生取决于队列结构，而非调参。** 相同的算子、剂量、种子与稳定性干预，在两个真实队列上给出相反结果；起决定作用的是标签类型（病因型还是序数型）、相对于可测边界的供者数量，以及评估所取的层级（同源切片膨胀效应意味着，切片级交叉验证会在人们检查修复是否奏效之时，悄悄报告再识别）。因此在训练之前，人们就可以问：我拥有的是哪一种标签？该信号需要多少供者才能在去身份化后存活？又该在哪个层级评估？

第四，**存活的信号是可解释的信号。** 角化富集说明，接受协议保住的并非任意残差，而是经典的 HPV 生物学；这也支持把该协议当作发现滤波器来用：通过经审计修复的内容，就是跨队列迁移的候选。

**局限性。**（i）只有一个外部真实队列（n = 16，每患者一张切片）；边界是在仿真上用线性岭探针作为读数标定的——子空间论证预测其与骨架无关，GCN 复现也支持这一点，但其他编码器族尚未测试。（ii）修复族是对抗式的；对比臂（跨患者正对）仍是合理的替代方案，本文有意未予展开。（iii）接受轴（ii）——样本内记忆的清除——在身份混杂对照上只做到部分（约 12%），因为记忆会搭乘植入指纹之外的供者特异成分；我们把它报告为样本内指标所能证明之事的上界，而非一项成功——在本身没有真信号可清除的身份混杂队列上，部分清除是预期结果，而非短板。（iv）完全泛化点（在非加固复跑中观察到，τ 处于天花板，LDI 门仅因回弹而超出）值得解读，但在每剂量三个种子下，我们不把剂量最优点当作精确量；全文只报告范围与种子分散度。（v）边界 n* 是针对单一信号通道结构（共享程序 + 供者指纹）定义的；带有额外泄漏通道（批次、平台）的队列需要各自的相图，而我们所发布的生成器与训练器，使其成为一次配置更改，而非一项新研究。（vi）外部队列上的下游临床终点在修复后并未改善（基线 LODO HPV AUROC 0.906，修复后 0.766–0.813；表 S9）：该队列每患者只有一张切片，不存在可移除的同源切片泄漏，因此修复付出的纯粹是保真代价。我们明确将其写为临床论断的边界——修复只在确实存在泄漏通道的地方移除泄漏；在这类队列上，它的贡献是为"有多少信号可供者迁移"提供经审计的度量，而不是提升下游准确率。

**实用协议。** 对于小队列 ST 研究：（1）在做任何建模论断之前，先用 LDI 审计；（2）若存在泄漏，不要尝试事后清理——用患者对抗修复重训；（3）核对命题 1 的比值 τ_base/σ̂——若超过约 2.35，则"移除并保留"双门不是合适的接受方式，应改用三轴协议；（4）在供者级验证；（5）只接受供者预算高于其信号强度对应可行性边界的队列；（6）用解码器读出存活的程序，并对照已知生物学检查。以上每一步都是所发布仓库中的一个脚本。

## 实验方法

### 资源可得性

**数据。** 外部队列为 GSE268014[13]（Visium，HPV+ / HPV− HNSCC；16 例患者的平衡子集，8 例 HPV+ 与 8 例 HPV−，共 57,872 个 spot，平均每切片 3,617 个 spot），来自 Gene Expression Omnibus。宫颈队列（35 张带序数型严重度标签的 Visium 切片）如姊妹研究[1] 所述（10x Genomics 公开数据集与 GSE217237[14]）。仿真队列由随文发布的仿真器以固定种子生成。

**代码。** 所有训练、仿真、审计、聚合与分析脚本，连同精确种子与配置清单，发布于 [投稿前待最终确定的仓库 URL]。

### 记号、探针与仪器

设有 m 张切片的队列（嵌入取训练后的切片均值），y ∈ {0,1}^m 为标签向量，X 为嵌入矩阵：**τ_in** 是岭探针得分 X·w 与 y 的样本内 Kendall 关联，w 在全部 m 张切片上拟合；**τ_LOO** 是其留一法版本（探针在 m−1 张上拟合，在留出切片上打分）；**τ_LDO** 为供者级版本，一个供者的所有同源切片一并留出。**标签依赖指数**为 LDI = (τ_LOO − τ⊥)/σ̂，其中 σ̂ 是 τ_LOO 置换零假设的标准差（重拟合推断：每次置换都重新拟合探针），在 B = 2,000 次置换、种子 20261010 下计算，τ⊥ = 0.001 为零假设下界；校准检测门为 LDI < 1.645（单侧 5%）。类规模为 (n₀, n₁) 的二元标签，其**解析天花板** τ_max = n₀n₁ / sqrt((n₀n₁ + T)(n₀n₁))，其中 T = C(n₀,2)+C(n₁,2)；例如 (50,40) 为 0.707、(18,14) 为 0.713、(8,8) 为 0.7303。置换深度敏感性：以 B = 10,000 重算外部队列零假设，σ̂ 变动不超过 4.4%，未翻转任何一次门判决（0/15；表 S4）。

### 命题 1

见结果部分的陈述与证明；可行性阈值为 τ_base/σ̂ < 1.645/c（c = 0.7 时约 2.35）。实测比值：共享程序仿真 5.8；宫颈约 2.4；HNSCC 约 2.2（表 1）。

### 修复算子（方法 B）

编码器：两层图注意力（GAT；GCN 变体见表 S5），作用在 spot 级 kNN 图（k = 6，双向；切片坐标按每切片 50,000 单位偏移，以阻断跨切片连边）。解码器：线性，在并集面板（每样本取方差最大的 2,000 个基因，再对样本取并集；HNSCC 队列为 6,586 个基因）上重建 log1p 文库归一化表达。损失：重建项 + λ · CE(对抗器(GRL(z)), 患者 ID)；GRL 反转强度在预热窗口（W 个 epoch）内 α = 0，随后 α = min(1, 2·(epoch − W)/(epochs_total − W)) · α_cap，α_cap = 1。对抗器：两层 MLP。基础配置 W = 0；稳定性变体额外加入 W = 50、裁剪阈值 1.0 的梯度裁剪，以及对对抗器的谱归一化。优化：Adam，300 个 epoch，全批次。剂量 λ ∈ {0, 0.5, 1, 2, 5}；每单元三个训练种子（与仿真种子一致）。硬件：云实例（AutoDL）上的单块 NVIDIA GeForce RTX 4080 SUPER GPU（32 GB），外部队列上每次训练约 30 秒。

### 仿真

生成器（随文发布）：jitter 过的六边形网格上的 spot（每切片 1,500 个）；稀疏对数正态背景表达，每个基因带供者级批指纹 N(0, 0.6)；逐供者的程序响应系数。共享程序臂植入振幅（0.5–2.5）；身份混杂臂使用类平衡的指纹；弱信号臂带异质性（响应范围与丢失率同姊妹研究）。相图：供者 n ∈ {4, 8, 16, 32, 64}（5:4 类比例），k ∈ {1, 2, 4, 8} 张切片/供者，信号 {1.0, 0.3}；供者不变参数在同一供者的各切片间共享；每单元三个种子（表 S6 边界单元用种子 3–4）。单元统计量：跨种子的平均 R = τ_LOO/τ_in。

### C3-lite 基因方向分析

在可得的四个严格配对（λ = 2，种子 0–2，以及 λ = 5 的最大剂量种子；外部队列，稳定性变体）上：在切片均值嵌入上以岭回归拟合 HPV 方向 d（α = 1，标准化）；基因载荷 L = W·d，经由各次运行自身的解码器 W（严格配对）；富集在唯一符号空间计算（6,586 条目面板 → 4,647 个唯一符号，重复条目按基因取 |载荷| 最大值），用超几何检验对照面板内 11 个标志物背景，并以 2,000 次抽样的置换零假设对照随机 100 基因集；四个严格配对全部列于表 S7。基因名经归一化处理（剥离平台前缀）。

### 统计分析

所有报告的判定都采用上述种子与置换深度下的校准 LDI；可迁移比例统计量为同一次运行内的 R = τ_LOO/τ_in（该运行在样本内拟合内容中供者可迁移的份额）。外部队列的门判决在 B = 10,000 下复核无误（表 S4）；其余门判决使用 B = 2,000。在复核中观测到的最大 σ̂ 扰动下（σ̂ 变动 4.4%，相对于 B = 2,000 的估计；LDI 按倒数缩放，最坏方向至多 +4.6%），没有任何已报告判决发生改变——在未直接复核的运行中，最接近门的数值（身份混杂最大 LDI = 1.55）至多移动到约 1.62，仍在门之下。
