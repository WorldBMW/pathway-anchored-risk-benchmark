# 撞车逐篇差异对比表（spEMO / OmiCLIP / Path2Space）

> 用途：投稿前 Related Work 与 Rebuttal 直接引用。检索日期 2026-08-17。

---

## A. spEMO — Leveraging Multi-Modal Foundation Models for Analysing Spatial Multi-Omic and Histopathology Data
- 出处：Nature (2026.02.05)；biorxiv 2025.08.23；Broad Institute
- 方法：统一（unify）来自 pathology FM + language model 的 embedding，分析空间多组学 + 组织病理数据。
- 覆盖任务：空间去卷积、细胞类型注释、空间域识别、基因程序推断等"通用空间任务谱"。
- 癌种：**癌症无关（cancer-agnostic）基础模型框架**。
- 风险评分：作为通用下游任务之一，无特定疾病语义。
- **与本基金差异**：
  - spEMO = 通用框架；本工作 = **宫颈 HPV 专属生物学发现**。
  - spEMO 不绑定 HPV / 宫颈；本工作风险评分显式锚定 HPV 相关空间生态位。
  - 本工作强调同切片 1:1 配对 + 自监督无外部标签，spEMO 未强调该配对严谨性。

---

## B. OmiCLIP — A visual–omics foundation model to bridge histopathology with spatial transcriptomics
- 出处：Nature Methods (2025.07.09 / online 2025.05.29)
- 方法：对比学习（CLIP 式）预训练 visual–omics 基础模型，链接 H&E 图像与转录组；并衍生 LOKI 平台连接 ST 与 H&E。
- 定位：**预训练基础模型**，目标是通用视觉-组学对齐表示。
- 癌种：通用，无特定癌种生物学 claim。
- 风险评分：**无**（专注表示学习）。
- **与本基金差异**：
  - OmiCLIP = 表示预训练；本工作 = 用冻结 FM 做**下游 HPV 风险发现**。
  - 本工作不训练新 FM，规避与 OmiCLIP 的方法学正面竞争，转而占据其未覆盖的"宫颈 HPV 应用空白"。
  - 可把 OmiCLIP 作为"更重的替代方案"在消融里对比（若算力允许）。

---

## C. Path2Space — AI-predicted spatial transcriptomics unlocks breast cancer biomarkers from pathology
- 出处：Cell (2026.05)；Ruppin 团队；DOI 10.1016/j.cell.2026.04.023
- 方法：
  1. 每个 spot 提 H&E tile → 颜色标准化 → **CTransPath** 提 768 维特征。
  2. MLP 将 768 维映射到 14,068 维基因表达（log10(count+1)）。
  3. 集成 + 空间平滑降噪。
  - 训练：Bassiouni Visium 队列 56,567 对；留一患者交叉验证。
  - 外部验证：HEST / Martinez / HTAN；FFPE 可泛化。
- 生物标志物：SpaCET 去卷积得细胞组成；SpaGCN 得 11 类空间簇 → 3 类 SpatioTypes（proliferation / immune-modulated / immune-inactive）；immune-inactive 预后差（TCGA HR=2.04, METABRIC HR=5.45）；HER2 SPAND 预测曲妥珠单抗 pCR AUC 0.69–0.83。
- 风险相关：基于 SpatioTypes 的 HR，**无单一综合风险评分，无 HPV**。
- 癌种：**仅乳腺癌**。
- **与本基金差异（最关键）**：
  - Path2Space = 乳腺癌 H&E→表达预测 + biomarker；本工作 = **宫颈 + HPV 空间生态位 + 可解释风险评分**。
  - 癌种完全不重叠（乳腺 vs 宫颈），生物学问题不同（激素/HER2 vs HPV 驱动）。
  - 本工作风险评分**显式可解释**并锚定 HPV 通路，Path2Space 仅 SpatioType HR 且无 HPV 语义。
  - 本工作用 UNI/UNI2（更强 FM）且做表达–形态联合对齐，而非单向 H&E→表达回归。

## E. Rebuttal 预案（审稿人最可能问的）
1. *"和 spEMO / Path2Space 有何不同？"*
   → 它们是通用/乳腺癌方法；本工作是首个宫颈 HPV-锚定的形态–表达风险发现，生物学问题不同。
2. *"风险评分新在哪？"*
   → 显式对应 HPV 整合/免疫逃逸通路活性，可解释，非重建副产物（对比 HE2ST/Path2Space）。
3. *"单例宫颈统计效力？"*
   → 宫颈 Visium 为描述性机制证据；统计主力为 TCGA-CESC 308 例 HPV 锚定（预先声明，非队列内预后）。
4. *"为何不训练自己的 FM？"*
   → 冻结 SOTA FM（UNI/UNI2）已是 2025–2026 标配；本贡献在生物学发现与 HPV 锚定，而非表示学习。
