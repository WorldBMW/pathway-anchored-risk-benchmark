## 1. 完整实验矩阵（7 组 + 外部验证 = 达二区）

### A. 主结果（1 组）
| run_id | 命令 | 产出 |
|--------|------|------|
| **HPV_UNI** | `python scripts/train_st.py --data data/st_visium/cervical_cancer_1 --epochs 60 --fm uni --device cuda --run_id HPV_UNI --lambda_hpv 1.0` | 主风险场、空间置换 DEG、TME 面板 → **最终选用模型** |

### B. 模块消融（4 组，一键出表）
> 用 `scripts/ablation_study.py` 批量跑，输出 `results/ablation_summary.json/.csv`

| run_id | 消融对象 | 对应论文表述 |
|--------|----------|--------------|
| FULL | 完整方法（= HPV_UNI） | proposed |
| BASELINE-CNN | 去掉病理 FM（用 from-scratch CNN） | 证明 FM 必要性 |
| NO-HPV | `--lambda_hpv 0` | 去掉 HPV 锚定项 |
| NO-NEIGH | `--lambda_neigh 0` | 去掉空间一致性项 |
| FM-UNI2 | `--fm uni2` | 换基础模型稳健性 |
| FM-CHIEF | `--fm chief` | 换基础模型稳健性 |

```bash
python scripts/ablation_study.py --data data/st_visium/cervical_cancer_1 --device cuda
```
> 注：CPU 上只会跑 FULL/BASELINE-CNN/NO-NEIGH（其余需 GPU 下载权重）。

### C. 与已有方法定量对比（1 组）
> `scripts/baseline_compare.py` 复现 HE2ST/Hist2ST 式 image→expression
> （frozen FM 特征 + KNN/ridge 回归），在留出 spot 上比 recon MSE / Pearson，
> 并验证"无疾病锚定"方法**无法**恢复 HPV 相关 DEG。

```bash
python scripts/baseline_compare.py --data data/st_visium/cervical_cancer_1 \
    --fm uni --device cuda --run_id BASELINE_HE2ST
```

### D. 跨癌种外部验证（1 条命令跑 4 队列）
> `scripts/cross_cohort_eval.py` 在 breast / ovarian / prostate / colon-HD 上
> 复用**同一套**训练与 DEG 代码，证明方法不止在宫颈上成立。

```bash
python scripts/cross_cohort_eval.py --root data/st_visium --device cuda \
    --epochs 40 --run_id XCOHORT
```
产出 `results/cross_cohort_XCOHORT.json`：每队列的 Moran's I、空间置换 DEG 数、
高风险场与 HPV 基因集重叠数。

### E. TCGA-CESC 独立 RNA-seq 一致性（已有，修正后可用）
```bash
python scripts/align_hpv.py --results results/results_HPV_UNI.json \
    --clinical data/cesc/cesc_clinical.csv --rnaseq data/cesc/cesc_rnaseq.csv
```
验证宫颈 Visium DEG 与 TCGA-CESC 独立队列 DEG 的方向一致性（sign agreement）。

## 3. 执行顺序建议（服务器）

1. 同步本机修复后的 `scripts/train_st.py`（含 detach 修复）到服务器。
2. 跑 A：`HPV_UNI` → 确认 `score_range` 展开、有显著 DEG。
3. 跑 B：`ablation_study.py`（GPU 全 6 组）。
4. 跑 C：`baseline_compare.py`（与 SOTA 对比）。
5. 跑 D：`cross_cohort_eval.py`（跨癌种）。
6. 跑 E：`align_hpv.py`（TCGA 一致性）。
7. 拉回所有 `results/*.json` 汇总。

## 4. 仍需注意的硬伤（非代码）

- **单样本宫颈**：`cervical_cancer_1` 仅 1 例。二区通常需要 ≥3 例宫颈才能称"队列"。
  当前 cross-cohort 用其它癌种替代，但宫颈本身需补 2–3 例。
- **TCGA 临床/表达文件**：`data/cesc/` 下需准备 `cesc_clinical.csv`、`cesc_rnaseq.csv`
  （align_hpv Layer2 依赖），当前可能缺失，需补数据。
- **外部验证是表达一致性，非生存**：当前 align_hpv 只做 DEG 方向一致；若要做
  C-index 生存验证，需宫颈患者生存数据（现缺）。
